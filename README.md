# Classical Machine Learning Projects

This repository contains two end-to-end classical machine learning projects covering data preprocessing, model development, evaluation, and deployment.


### 1. Loan Approval Prediction with Deployment

Build a machine learning classification model that predicts loan approval and deploy it using streamlit.


**Key Areas:**

* Data cleaning and preprocessing
* Classification model comparison
* Accuracy, Precision, Recall, F1-score and confusion matrix evaluation
* streamlit web application development
* Streamlit Cloud deployment


## Technologies

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn
* Streamlit

### Expected Outcome:
* A working loan approval prediction system with a deployed API/application.


## Project 2: Customer Churn Prediction

* Dataset Description 

* Target variable is Churn : 0 --> Customer still using the service

* 1 --> Customer has cancelled service 

## Objective

Build a machine learning classification system that predicts whether a customer is likely to stop using a company's service.

The project should demonstrate the complete machine learning workflow, from data preprocessing and exploratory analysis to model training, evaluation, and deployment.

## Requirements

### 1. Data Preparation

* Clean the dataset and handle missing values.
* Identify and handle duplicate or inconsistent records.
* Analyze the numerical and categorical features.
* Encode categorical variables appropriately.

### 2. Exploratory Data Analysis

### 3. Model Development

Train and compare multiple classification models, such as:

* Logistic Regression
* Decision Tree Classifier
* Random Forest Classifier
* Gradient Boosting 

You should establish a suitable baseline before comparing more advanced models.


### 4. Model Evaluation

Evaluate the models using appropriate classification metrics:

* Accuracy
* Precision
* Recall
* F1-score
* Confusion Matrix

Pay particular attention to **Precision, Recall, and F1-score**, rather than relying only on accuracy.

### 5. Model Selection

Compare the trained models and select an appropriate final model based on the evaluation results.

Explain why the final model was selected.



### 6. Application

Build a simple application using Streamlit that allows a user to provide customer information and receive a churn prediction.

The application should return:

* Churn prediction
